PDF Restrict Edit

License: LGPL v3
Odoo Version: 18.0

Overview

This module adds password protection to generated PDF reports (invoices, quotations, delivery slips, etc.) without requiring a password to open the document. It prohibits editing, copying content, assembling pages, and other modifications.

- No password prompt when opening the PDF – seamless for end users.
- Editing and copying are disabled – protects document integrity.
- Configurable master password – set once via Settings → PDF Security.
- Random password fallback – if no master password is set, a unique random password is generated for each PDF (logged for admin reference).

Features

- Encrypts all PDF reports generated by Odoo (QWeb + wkhtmltopdf).
- User password is empty – documents open instantly.
- Owner password is used to enforce restrictions (not shared with end users).
- Permissions allowed: only low-resolution printing (printing is allowed).
- Permissions denied: editing, copying, annotating, filling forms, assembling pages, extracting content.
- Works with standard Odoo reports: Customer Invoices, Quotations, Sales Orders, Delivery Slips, etc.
- No performance overhead – encryption is applied after PDF generation.

Installation

1. Copy the pdf_restrict_edit folder to your Odoo addons directory.
2. Go to Apps → update the module list.
3. Search for PDF Restrict Edit and install it.
4. (Optional) Install pypdf or PyPDF2 for better performance. The module works with either; if neither is present, encryption is skipped.

   pip install pypdf

5. Restart Odoo server.

Configuration

After installation, navigate to:

Settings → PDF Security

1. Enter a master password (leave empty to auto‑generate a random password for each PDF).
2. Click Save.

The master password is stored securely in ir.config_parameter and is used as the owner password for all subsequent PDFs. It is never displayed again – if you forget it, you can change it by entering a new one in the same form.

Usage

Once configured:

- Create or open any document that generates a PDF report (e.g., Customer Invoice, Quotation).
- Print the document (using your usual print button).
- The generated PDF will be encrypted with the following restrictions:
  - Opening: no password required.
  - Editing: disabled.
  - Copying content: disabled.
  - Annotations: disabled.
  - Form filling: disabled.
  - Page extraction/assembly: disabled.
  - Printing: allowed (low quality only).

To verify the restrictions, open the PDF in Adobe Acrobat Reader (not a web browser) and check File → Properties → Security. You will see the restrictions listed.

Compatibility

- Odoo versions: 18.0 (may work with 17.0, 16.0 with minor adjustments).
- Dependencies: base, no other Odoo modules required.
- Python libraries: pypdf (recommended) or PyPDF2. If neither is available, the module falls back to unencrypted PDFs (no protection).

Troubleshooting

Q: The PDF still opens without restrictions in Chrome / Edge.
A: Web browsers ignore PDF restriction flags. Always test with Adobe Acrobat Reader. The protection is still active when opened in proper PDF readers.

Q: I get an error "No module found" when submitting to Odoo Apps.
A: Make sure your repository structure is:

repository-root/
└── pdf_restrict_edit/
    ├── __manifest__.py
    ├── models/
    ├── views/
    ├── security/
    └── static/

Do not place the module files directly at the root – they must be inside a folder with the module name.

Q: After installation, I don't see the menu item "PDF Security".
A: Check that your user has System rights (Settings → Users & Companies → Users → Access Rights → "Settings" group). Also, ensure the module is marked as installed. If still missing, restart Odoo and update the module (Apps → Upgrade).

Q: The PDF is not encrypted at all.
A: Verify that pypdf is installed (pip list | grep pypdf). Check the Odoo logs for any error messages related to PDF encryption. The module will log a warning if no PDF library is found.
